# 藻类细胞分裂谱系复原

从连续荧光帧的候选细胞斑点中，**联合选择**斑点与帧间连接，恢复一株藻细胞的
分裂谱系。计算全部在浏览器内完成，不上传任何数据。

## 生物学 / 组合模型

- 录入 **4 至 7 个**按时刻排列的帧，每帧 **2 至 8 个**唯一斑点
  （整数坐标 x/y、整数亮度）。
- 连接只允许：
  - **相邻帧**（`gap=1`）：位移 ≤ 相邻帧最大位移；
  - **跨恰好一帧漏检**（`gap=2`）：中间帧无该细胞斑点，两端直线位移
    ≤ 2 × 最大位移，受「允许漏检帧数」总额度约束。
- 一个细胞每步要么**保持为一个后代**，要么**分裂为恰两个后代**，不允许消亡。
- 每个非起始斑点**恰有一个祖先**；同一斑点不得被两支同时采用。
- 所有存活支必须从**起始斑点**出发到达末帧，末帧存活细胞数恰为设定值。
- **分裂不应期**（可选，门槛 2–4 个帧间）：起始细胞的首次分裂不受限制；此后
  每个女儿从零累计分裂年龄——普通连接增加 1 个帧间，跨漏检连接按真实跨度
  增加 2 个帧间；只有年龄达到门槛的支才允许再次分裂，分裂后两个女儿重新归零。
  不应期在联合选择斑点与连接时直接约束每条存活支（携带分裂年龄），而非先按
  原规则求出谱系再删除过早分裂。
- 裁决顺序（依次比较）：
  1. 采用斑点**总亮度最高**；
  2. **漏检段数最少**；
  3. **输入顺序稳定裁决**：逐帧比较采用斑点的输入序号，再比较母本编号。

因此不会逐帧贪心挑选最亮斑点而把杂质或不同个体串成同一支。

当终帧目标数与祖先/位移/漏检约束无法同时满足时，编辑草稿保留，页面指出
**最早断开的帧间**（如「第 1 帧 → 第 2 帧」）。启用不应期后，若所有候选都
要求某支过早再分裂，页面另行指出**最早被不应期阻断的帧间、母细胞及其尚缺的
等待帧间**（年龄达到门槛后即可分裂）。任一帧、限制、开关或门槛被修改后，旧
谱系立即作废并提示重新复原（草稿保留在编辑区与浏览器 localStorage）；未启用
不应期时，原输入、结论与证据保持一致。

## 本地运行（无需 Docker）

需要 Node.js ≥ 20（零第三方依赖）：

```bash
npm start                 # 默认 http://localhost:8080
WEB_PORT=9000 npm start   # 自定义端口
```

## Docker 运行

```bash
docker compose up web --build        # 浏览器打开 http://localhost:8080
WEB_PORT=9000 docker compose up web  # 用 .env 或环境变量自定义端口
```

网页端口完全由 `WEB_PORT` 控制（`.env` 可参考 `.env.example`）。

## verify 一次性校验服务

健康检查通过后，`verify` 服务自行执行**单元测试 → 构建 → 含分裂与漏检的谱系
烟测**，并以容器退出码报告结果：

```bash
docker compose up --build \
  --abort-on-container-exit --exit-code-from verify
echo $?    # 0 表示全部通过
```

三项也可不依赖 Docker 直接运行：

```bash
npm test     # node:test 单元测试（含 ~2000 组随机输入与独立暴力枚举对拍，
             # 以及启用分裂不应期后与带年龄暴力枚举的对拍）
npm run build  # 语法检查 + 静态资源完整性 + 构建清单
npm run smoke  # 健康检查 / 静态资源 / 分裂+漏检谱系 / 不可行最早断帧 /
               # 不应期连续分裂阻断 / 跨漏检计龄
```

## 求解方法

带备忘的深度优先联合枚举：状态为「某帧边界上的存活斑点集合 + 正在漏检中的
母本集合 + 剩余漏检配额」，逐帧联合决定每支的保持/分裂/漏检，并在同一转移内
保证斑点不被两支共用；同一状态的最优后缀只求解一次。配合末帧目标数的增长上界
剪枝，在 4–7 帧、每帧 ≤8 斑点的规模下即时返回。不可行时通过前向可达性与
后缀可行性，定位最早没有任何可行谱系穿过的帧间。

启用分裂不应期后，每条存活支额外携带「分裂年龄」（普通连接 +1、跨漏检 +2、
分裂女儿归零，起始支首次分裂不受限）；年龄达到门槛才放行分裂。后缀记忆化在
相同掩码下额外按年龄支配（更成熟且额度更多的配置不可行 ⇒ 更年轻配置必不可行）
与漏检配额单调性剪枝。若整体不可行，则在一个**放行过早分裂的松弛引擎**中沿
强制引擎的合法前缀展开，找出最早「要继续就必须有支年龄不足而分裂」的帧间、
母细胞与尚缺帧间；同帧多个候选（例如经漏检 +2 成熟的支）聚合取尚缺最少者。
